# Blood Vignette

**Author:** Evga314  
**Mod ID:** `bloodvignette`  
**Minecraft:** 26.3  
**Loader:** Fabric 0.19.5+  

Beautiful pulsing blood-red vignette and a distinctive warning icon that appear when your health is low. The effect pulses with a heartbeat rhythm and plays a subtle heartbeat sound.

## Features

- **Blood vignette** – full-screen deep red/burgundy vignette that pulses like a stressed heart.
- **Warning icon** – organic heart-shaped icon with an exclamation mark, predominantly red and burgundy, also pulsing.
- **Heartbeat sound** – quiet double-thump synchronized with the visual pulse.
- **Configurable threshold** – default 6 health points (3 hearts). Adjustable from 1 to 20 in Mod Menu.
- **Toggles** – independently enable/disable vignette and icon.
- **Volume & pulse strength** – fine-tune the experience.

## Dependencies

- Fabric API
- Cloth Config (for the config screen)
- Mod Menu (recommended)

## Building

```bash
./gradlew build
```

The output jar will be in `build/libs/`.

Requires **Java 25**.
